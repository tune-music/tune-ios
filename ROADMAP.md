# Полный план

Цель: полноценный клиент Яндекс Музыки для iPhone — расположение элементов привычное по официальному приложению, оформление своё (Liquid Glass на iOS 26), плюс возможности Tune: треки без цензуры и офлайн.

Отметки: `[x]` сделано, `[~]` сделано частично или не проверено на живом аккаунте, `[ ]` не начато.

**Как проверяется.** Код собирается только в GitHub Actions. Интерфейс проверяется по снимкам симулятора на демо-данных, сеть в этом режиме отключена. Всё, что ходит в Яндекс, окончательно проверяется на телефоне.
